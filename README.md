# Personal Portfolio — Mohamed Sheba

A modern, responsive personal portfolio built with **React** and **Vite**, showcasing my front-end development skills, projects, experience, and contact information through a clean dark-themed interface.

## Live Demo

**[View My Portfolio](https://mohamedsheba.github.io/Personal-Portfolio/)**

## Features

- **Responsive Design** — Optimized for desktop, tablet, and mobile devices.
- **Modern Dark UI** — A clean interface with a dark navy background and electric blue accents.
- **About Me** — An introduction to my background and front-end development journey.
- **Skills Section** — Highlights my technical skills and tools.
- **Projects Showcase** — Displays selected projects with screenshots, descriptions, live demos, and source code links.
- **Experience Section** — Highlights my front-end development training and learning journey.
- **Contact Section** — Provides ways to get in touch.
- **CV Access** — Options to view and download my CV.
- **Smooth Interactions** — Subtle transitions and hover effects for a better user experience.

## Getting Started

Follow these steps to run the project locally.

### Prerequisites

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/mohamedsheba/Personal-Portfolio.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Personal-Portfolio
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

### Build for Production

To create an optimized production build, run:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
